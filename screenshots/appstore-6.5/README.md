# App Store screenshots — 6.5" iPhone

1284 × 2778 px. Derived from [`../appstore-6.9`](../appstore-6.9) rather than re-captured:
each 1320 × 2868 original was resampled to 1284 wide (×0.9727) and then centre-cropped
12 px of height. The trimmed strip is black bezel above the status bar and below the home
indicator — no UI is lost.

App Store Connect's 6.5" slot accepts 1242 × 2688 or 1284 × 2778; this set uses the
larger of the two. Same eight screens, same filenames, same order as the 6.9" set —
see that folder's README for the screen-by-screen table.

## Before uploading

Same caveat as the 6.9" set: these are captures of **live production data** — real
parishioner names and profile photos, including minors in `05`. Replace the names and
avatars with placeholder data, or drop the affected shots, before publishing or committing.
