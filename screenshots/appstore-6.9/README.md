# App Store screenshots — 6.9" iPhone

1320 × 2868 px, captured on an **iPhone 16 Pro Max** simulator (iOS 18.5) running the
dev client against a local Metro bundle. Status bar is overridden to Apple's standard
9:41 / full signal / full battery.

A 6.5" set derived from these images lives in [`../appstore-6.5`](../appstore-6.5).

App Store Connect currently accepts a single iPhone set at the 6.9" display size
(1320 × 2868 or 1290 × 2796) and scales it down for every smaller iPhone, so this
directory is the only iPhone set the listing needs. Up to 10 images, shown in filename order.
